Java necə işləyir

Mövzu seç, kod yaz və daxildə nə baş verdiyini addım-addım gör.

Memory

JVM: Stack və Heap

Primitive-lər, object-lər, String Pool, frame-lər və GC. Kodun memory-də hara düşdüyünü sətir-sətir izlə.

String s
int a4
int[] d

Garbage Collection

Object nə vaxt silinir? GC root-ları, mark-sweep, Eden, Survivor, Old və memory leak.

o = null;
// no root, GC can remove it

String daxildən

String-in daxili quruluşu: byte[], LATIN1 və UTF16, emoji-nin uzunluğu, paylaşılan array və += qiyməti.

"çörek"  5 byte
"çörək" 10 byte

Object yaddaşda

Bir object neçə byte tutur: header, mark word, padding, field sırası, array-lər və 32 GB sərhədi.

new Object();
// 12 byte header + 4 padding

Collection-lar

HashMap necə işləyir

hashCode, bucket, collision və resize. Key-in table-dakı yerini necə tapdığını bit-bit izlə.

0"Aa"next"BB"
1null
14"Aysel"

TreeMap necə işləyir

Red-black tree-ni canlı izlə: insert, recolor, rotation, remove və sıralı axtarış.

m.floorKey(35);
// O(log n)

Concurrency

Thread-lər

İki thread-i özün idarə et. Race condition, synchronized, volatile, CAS və deadlock.

count++;
// read, add, write

ConcurrentHashMap necə işləyir

Bir neçə thread üçün HashMap. Boş bucket-də CAS, dolu bucket-də lock, resize və null qadağası.

map.merge("c", 1, Integer::sum);
// CAS or a bucket lock

Virtual Thread-lər

Bir milyon thread necə mümkün olur: carrier, mount və unmount, pinning və virtual thread-in kömək etmədiyi hallar.

Thread.ofVirtual().start(task);
// 1 000 000 threads: 5.4 s

Dil və JVM

Bytecode

javac nə yazır? Operand stack, local variable-lar, i = i++ tələsi və finally-nin həqiqi forması.

iload_0
iinc 0, 1
istore_0

Class loading

Class nə vaxt yüklənir? Delegation, üç mərhələ, static və constructor sırası, klassik tələlər.

static { ... }
super();

Stream necə işləyir

Stream lazy-dir. Element-lər bir-bir keçir, sorted hamısını saxlayır, count bəzən heç nə işlətmir.

.filter(...).map(...)
.findFirst();
